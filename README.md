# Court Ledger - 纯离线羽毛球 AA 算账计算器

**Court Ledger** 是一款轻量、现代、零依赖的**纯离线羽毛球 AA 费用分摊计算器**。
基于 **100% 纯原生、零编译（Zero-Build）架构** 构建，打开浏览器即可秒开使用，无需任何后端服务或数据库支持。

---

## 🌟 核心特性 (Features)

1. 🏸 **智能分段场费平摊**：
   - 支持跨早场（优惠费率）与晚场（高峰费率）的分段计费。
   - 支持多片场地联动换算（1-4 片）。

2. 🧮 **Host 覆盖与用球分摊**：
   - 自动计算真实用球成本与单球平摊价。
   - 智能推荐附加加球数量以覆盖 Host 免单成本，支持计算额外盈利球数。
   - 实时呈现每人应付费用、真实总成本、总收款与净利润。

3. 📂 **纯离线 CSV 球场数据**：
   - 所有球场数据编码于 `frontend/venues.csv` 中。
   - 支持本地查看、添加、编辑、删除与一键恢复默认 CSV 数据，无需任何远程数据库。

4. 📋 **一键复制账单**：
   - 点击“复制账单明细”一键生成格式清晰的文字账单，方便发送至微信/WhatsApp 球友群。

5. 🌙 **现代化主题与交互**：
   - 支持深色 (Dark) / 浅色 (Light) / 跟随系统 (System) 主题一键无缝切换。
   - 原生滑动选择器与移动端抽屉选择面板。

## 🚀 快速使用 (Quick Start)

### 方式 1：直接打开（100% 离线，无需安装任何环境）
直接双击打开 `frontend/index.html` 即可使用完整计算功能！

### 方式 2：使用本地静态服务器启动
```bash
# 启动本地轻量静态服务 (端口 8000)
npm start

# 运行自动化单元测试
npm test
```
